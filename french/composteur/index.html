Composteur du futur

简单将来时不是一张要背的表，而是几块零件的拼装：一个词干，一个 r 铰链，一组从 avoir 借来的词尾。把词尾那一块换掉，同一个词干就变成条件式。不规则只发生在词干那一块，词尾永远规则。

01 · 主公式

两条公式，共用一个词干

Futur simple
词干r+词尾 A
[s|parle][r|r][f|ai] · [s|fini][r|r][f|ons] · [s|prend][r|r][f|ez]

词尾 A = avoir 现在时去掉 av：[f|ai] [f|as] [f|a] [f|ons] [f|ez] [f|ont]

Conditionnel présent
词干r+词尾 B
[s|parle][r|r][c|ais] · [s|fini][r|r][c|ions] · [s|prend][r|r][c|iez]

词尾 B = avoir 未完成过去时去掉 av：[c|ais] [c|ais] [c|ait] [c|ions] [c|iez] [c|aient]，也就是 imparfait 的词尾。

规则词干一句话：把不定式切到最后一个 r 为止。parler → [s|parle][r|r]，finir → [s|fini][r|r]，prendre → [s|prend][r|r]（-re 动词就是把最后的 e 切掉）。铰链 r 其实就是不定式自己的 r。

铁律：所有将来时和条件式的词干都以 r 结尾，包括全部不规则词干，没有例外。看到 [r|r] + [f|ai]/[c|ais] 这个组合，就是这两个时态。

ab 词干（规则） ab 词干（变形） r 铰链 d 桥接音 ai 词尾 A · 将来 ais 词尾 B · 条件 / 未完成 parl nous 词干
02 · 拼装台

选一个动词，再换词尾模块

词干一动不动，只有最右边那块在换。这就是“一个不规则词干背一次，用十二次”的意思。

parler

avoir · présent → 词尾 A

j’[f|ai]ai
tu[f|as]as
il[f|a]a
nous[x|av][f|ons]ons
vous[x|av][f|ez]ez
ils[f|ont]ont

avoir · imparfait → 词尾 B

j’[x|av][c|ais]ais
tu[x|av][c|ais]ais
il[x|av][c|ait]ait
nous[x|av][c|ions]ions
vous[x|av][c|iez]iez
ils[x|av][c|aient]aient

同一个生成器：拿 avoir 的某个时态，削掉 av，剩下的就是词尾。现在时有四个人称本来就没有 av，所以只削 nous / vous；未完成过去时六个全削。

03 · 矩阵

两个维度，四个格子

把“词干”和“词尾”当成两根独立的轴，三个时态落在同一张表里，第四格是空的。

词尾 Aavoir 现在时 − av
词尾 Bavoir 未完成 − av
R 词干不定式切到 r
futur simpleje [s|parle][r|r][f|ai]nous [s|fini][r|r][f|ons]
conditionnelje [s|parle][r|r][c|ais]nous [s|fini][r|r][c|ions]
nous 词干nous 现在时 − ons
无此时态但 -er 动词 passé simple 的单数恰好借住在这里：je [n|parl][f|ai]、tu parlas、il parla。来源不同，只是撞形。
imparfaitje [n|parl][c|ais]nous [n|finiss][c|ions]

同一个 je，四种形式：r 和 s 各是一个开关

无 r · 无 s — passé simple[n|parl][f|ai][paʁ.le]
无 r · 有 s — imparfait[n|parl][c|ais][paʁ.lɛ]
有 r · 无 s — futur[s|parle][r|r][f|ai][paʁ.lə.ʁe]
有 r · 有 s — conditionnel[s|parle][r|r][c|ais][paʁ.lə.ʁɛ]

这四格和上面的矩阵是同一张表，只是缩到了 je 一个人称。词尾 -ai [e] 与 -ais [ɛ] 在不少人的口语里已经合并，所以说话时真正承重的是铰链 r。双 r 动词还多一组听得出的对立：je courais [kuʁɛ] / je courrais [kuʁʁɛ]。

04 · 不规则词干

五个家族，按形状记

不规则全部集中在词干主体，铰链 r 和词尾都不变。按“变形方式”分组，比按字母表背更容易成块。

家族 A · 短根

整块替换

être[i|se][r|r]
avoir[i|au][r|r]
savoir[i|sau][r|r]
faire[i|fe][r|r]
aller[i|i][r|r]

只能整块背，但数量少。avoir / savoir 押韵：aur / saur。aller 的 ir 来自拉丁语 īre。

家族 B · -oir → -vr

删掉 oi，留下 v

devoir[i|dev][r|r]
recevoir[i|recev][r|r]
apercevoir[i|apercev][r|r]
pleuvoir[i|pleuv][r|r] il pleuvra

所有 -cevoir 都走这条。同为 -oir 的 voir、pouvoir 去了家族 C，savoir 去了家族 A。

家族 C · 双 r

词干坍缩成 rr

pouvoir[i|pour][r|r]
voir[i|ver][r|r]
envoyer[i|enver][r|r]
courir[i|cour][r|r]
mourir[i|mour][r|r]
acquérir[i|acquer][r|r]

voir / envoyer 押同一个 verr。courir、mourir 只是丢掉了 i，于是词干的 r 和铰链 r 贴在一起，读音上能听到拉长的 r。

家族 D · d 桥

n / l 撞上 r，中间长出 d

venir[i|vien][d|d][r|r]
tenir[i|tien][d|d][r|r]
vouloir[i|vou][d|d][r|r]
valoir[i|vau][d|d][r|r]
falloir[i|fau][d|d][r|r] il faudra

n+r、l+r 发音不顺，古法语在中间插入 d（l 同时元音化成 u）。这块零件在动词之外也存在：cinerem → cendre、generum → gendre、minor → moindre；m+r 则插 b：numerum → nombre、camera → chambre。所有 -venir、-tenir 的派生词（devenir, obtenir, retenir…）都继承 iendr。

家族 E · je 现在时 + r

拼写变化的 -er 动词

acheterj’achète → [i|achète][r|r]
leverje lève → [i|lève][r|r]
appelerj’appelle → [i|appelle][r|r]
jeterje jette → [i|jette][r|r]
employerj’emploie → [i|emploie][r|r]
cueillirje cueille → [i|cueille][r|r]

规则：取 je 的现在时形式，后面接 r。payer、essayer 两种都可以（paierai / payerai）。cueillir 是一个借用 -er 模式的 -ir 动词。例外：préférer 虽然是 je préfère，传统写法仍是 préférerai，1990 年拼写修订也接受 préfèrerai。

记忆策略

一个词干，十二个格子

每个不规则词干只要记一次（例如 [i|vien][d|d][r|r]），它会同时出现在将来时 6 个人称和条件式 6 个人称里。

检验方法：说出 je ___rai 和 je ___rais，如果两者的词干不一样，一定是哪里错了。

05 · 插槽

这些块还能插到哪里

同样的零件在句法层面继续组合。词干表示“之后会发生”，词尾表示“从哪个时间点看”：词尾 A 站在现在，词尾 B 站在过去。

si + présent → futur

真实条件

S’il fait beau, nous [s|sorti][r|r][f|ons].

si + imparfait → conditionnel

假设条件 · 同一组词尾 B 出现在逗号两边

S’il [n|fais][c|ait] beau, nous [s|sorti][r|r][c|ions].

quand / dès que + futur

法语在时间从句里也用将来时，中文和英语不这样做

Quand tu [s|arrive][r|r][f|as], appelle-moi.

futur dans le passé

主句移到过去 → 词干不动，词尾 A 换成 B

Il dit qu’il [i|vien][d|d][r|r][f|a].

Il a dit qu’il [i|vien][d|d][r|r][c|ait].

复合时态：整套系统插进助动词槽

[avoir / être 的将来或条件] + participe passé

Quand j’[i|au][r|r][f|ai] [a|fini], je partirai. futur antérieur

Si j’avais su, je [i|se][r|r][c|ais] [a|venu(e)]. conditionnel passé

礼貌用法

条件式把请求从“现在”挪远一步

Je [i|vou][d|d][r|r][c|ais] un café.

[i|Pour][r|r][c|iez]-vous m’aider ?

对照：futur proche

aller（现在时）+ 不定式 · 同样的原料，没有焊死

Je vais parler. 比较：je [s|parle][r|r][f|ai]

futur proche 是“助动词 + 完整不定式”，两块分开放；futur simple 在历史上也是“不定式 + avoir”，只是两块已经焊在一起，见下一节。

06 · 接缝

这条接缝从拉丁语来

古典拉丁语的将来时 cantābō 在口语里消失了，取而代之的是“不定式 + habeō（我有 / 我必须）”，后来两块焊成一个词。

cantāre + habeō[s|chante][r|r][f|ai]“我有要唱的” → “我将唱”。词尾 A 就是 avoir 现在时。
cantāre + habēbam[s|chante][r|r][c|ais]同一结构，助动词换成未完成过去时，就是条件式。
西班牙语cantaré / cantaría同一套拼装。条件式词尾 -ía 同样是 imperfecto 的词尾。
意大利语canterò / canterei条件式第二块借的是完成体 *hebui（ebbi），所以同一个槽装了不同的零件。
葡萄牙语dar-te-ei · dar-te-ia代词至今还能插进不定式和词尾之间（mesóclise），等于把接缝撬开给你看。
