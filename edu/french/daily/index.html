Pratique quotidienne

One verb form a day: recognised, taken apart, and put back into sentences.

每天从一个词形进入：辨认、拆解，再放回句子里读。

  1. N° 0619 octobre 2026j’avais réservé愈过去时：相对于某个过去时刻，已经发生的事；从一段博物馆故事读出过去的时间层次。Plus-que-parfait过去时间参照avoir/être 助动词过去分词配合→
  2. N° 0518 octobre 2026s’en souvenaient在词形前认出代词槽：s’ 和 en 与 se souvenir 一起整体读取。se souvenir de / en代词槽imparfaitsubjonctif→
  3. N° 0417 octobre 2026aurait dû一个已经过去的「本应该」：从 devoir 进入条件式过去时。devoirconditionnel passéavoir + participe passéplus-que-parfait→
  4. N° 0316 octobre 2026prendraient从 prenaient、prendraient、prennent 的差别，进入 prendre 的完整词形家族。prendre 词族prend- / pren- / prenn-conditionnelsubjonctif→
  5. N° 0215 octobre 2026voyions多出来的一个 i：从 voyons 到 voyions，从词形辨认走向语境判断。voirvoy- / voi- / verr-imparfait = subjonctifprévoir→
