Décomposeur

写的时候从左往右拼：词干 → 时态标记 → 人称。读的时候顺序反过来，从右往左拆：先看最后几个字母是谁，再看它前面贴着哪个时态标记，最后才看词干属于哪个动词。识别慢，往往是因为在用写的顺序去读。

从右往左读 · parleraient
parle④ 词干parle- ← parler
r③ 铰链 r将来系
ai② -ai-imparfait 系
ent① -entils

② 和 ③ 同时出现 = conditionnel。只有 ② 是 imparfait，只有 ③ 是 futur，两个都没有就去看 subjonctif 或 présent。

02 · 共享模块地图

三个词干来源 × 四组词尾

Composteur 里的 2×2 矩阵在这里扩展到 3×4。每个有内容的格子都是一个时态（或其中几个人称）。带紫红描边的两格词尾完全相同，所以会同形。

枢纽 1

不定式

  • futur simple 6 个人称
  • conditionnel 6 个人称

词干不规则的约二十个动词，见 Composteur 的五个家族。

枢纽 2

nous 的现在时

  • imparfait 6 个人称
  • subjonctif 的 nous / vous
  • participe présent（prenant, voyant, finissant）
  • impératif 的 nous（prenons !）

例外很少：imparfait 只有 être（ét-）；participe présent 只有 étant、ayant、sachant。

枢纽 3

ils 的现在时

  • subjonctif 的 je / tu / il / ils

词干另起炉灶的只有几个：être, avoir, aller (aill-), faire (fass-), pouvoir (puiss-), savoir (sach-), vouloir (veuill-)。

结论：把现在时的 nous 和 ils 两个形式背牢，imparfait、subjonctif、participe présent 就几乎不用另外背。B 和 C 在 nous / vous 两格完全同形，所以 nous prenions 既是 imparfait 也是 subjonctif。只有虚拟式词干不规则的动词能区分：faisions / fassions，pouvions / puissions，savions / sachions，étions / soyons，avions / ayons。

03 · 人称层

最右边那块几乎不随时态变

这就是识别时要先看人称的原因：最右边这一层最稳定，跨时态几乎不变，先把它读掉，剩下的字母就少了。

05 · 同形与近形

辨认时最容易停顿的地方

识别慢通常卡在这些位置：两个形式只差一个块，或者两个块拼出完全相同的字符串。

完全同形

imparfait = subjonctif（nous / vous）

[n|parl][sh|i][p|ons]imparfait
[n|parl][sh|i][p|ons]subjonctif

形式上无法区分，要靠句子里的 que 和主句的动词。

完全同形

présent = passé simple（-ir 单数）

[base|fini][p|s] · [base|fini][p|t]présent
[base|fin][ps|i][p|s] · [base|fin][ps|i][p|t]passé simple

finir、dire、rire 都是这样：dis / dit、ris / rit。看到复数才能分开：finissons / finîmes。

完全同形

présent = subjonctif（-er 动词）

[base|parl][p|e] · [base|parl][p|ent]présent
[l|parl][sj|e] · [l|parl][p|ent]subjonctif

-er 动词的 je / tu / il / ils 两套完全一样。finisse、prenne 这类 -ir、-re 动词才有可见的 -e-。

差一个 i

stem 本身以 i / y 结尾

[base|voy][p|ons]présent[n|voy][sh|i][p|ons]imparfait / subj
[base|étudi][p|ons]présent[n|étudi][sh|i][p|ons]imparfait / subj

croyions、riions、étudiiez 同理。看到 -yions 或 -iions，第二个 i 才是时态标记。

差一个 r

courais / courrais

[n|cour][b|ai][p|s]imparfait
[i|cour][r|r][b|ai][p|s]conditionnel

词干自己的 r 不算铰链。courir、mourir、pouvoir（pourr-）、voir（verr-）都有双 r，需要数 r 的个数。

差一个 s

-ai / -ais

[base|parl][ps|ai]passé simple[n|parl][b|ai][p|s]imparfait
[s|parle][r|r][f|ai]futur[s|parle][r|r][b|ai][p|s]conditionnel

同一个 s 开关，在有 r 和没有 r 的两组里各出现一次。

-ent 阶梯

同样以 -nt 结尾，前面那一块决定时态

[base|parl][p|ent]présent
[n|parl][b|ai][p|ent]imparfait
[s|parle][r|r][f|o][p|nt]futur
[s|parle][r|r][b|ai][p|ent]conditionnel

ils 那一列从下往上读，每往上一格就少一个块。

正字法垫片

mangeais / mangions

[n|mange][b|ai][p|s]a 前加 e[n|mang][sh|i][p|ons]i 前不加
[n|commenç][b|ai][p|s]a 前用 ç[n|commenc][sh|i][p|ons]i 前用 c

这里的 e 和 ç 只是为了保持 g、c 的软音，不是时态标记，拆的时候算在词干里。

外形撞车

avoir 的 ait 和 imparfait 的 -ait

[i|ai][p|t]avoir 虚拟式 · qu'il ait
[n|av][b|ai][p|t]avoir imparfait · il avait

短词更难拆。ait 只有词干和人称两块，avait 比它多出 av 那一块。

06 · 来源

-ai- 从哪里来

habēbat[n|hab][b|ēba][p|t]拉丁语 imperfect：tense sign -ēba-。
avoit[n|av][b|oi][p|t]古法语：-ēba- 的 b 脱落，变成 -oi-。十八世纪的书里还写 il avoit, j'étois。
avait[n|av][b|ai][p|t]读音早已变成 [ɛ]，拼写在 1835 年的学院词典里正式改成 -ai-，伏尔泰是这个拼法最有名的推动者。
habēbāmus[n|hab][b|ēbā][p|mus]nous / vous 也来自 -ēbā-：b 脱落后在古法语里成了 -iiens / -iiez，后来 -iens 按现在时的 -ons 类推成 -ions，于是和 subjonctif 撞形。
